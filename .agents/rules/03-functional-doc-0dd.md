# Regla 03: Estándar Zero Document Debt (0DD)

## 1. Principio Fundamental
El código sin documentación viva es deuda técnica inmediata. Ningún ítem puede marcarse como `Done` en el backlog sin la firma del `@documentator` en el Gate 5.

## 2. Componentes de la Documentación Viva
1. **Guías Funcionales (`docs/es/` y `docs/en/`):** Explicación clara y accesible para usuarios finales del nuevo comportamiento incorporado.
2. **Catálogo de APIs (`docs/knowledge/API_CATALOG.md`):** Tabla actualizada de endpoints, métodos HTTP, cabeceras, contratos de petición/respuesta y códigos de retorno.
3. **Modelos de Datos (`docs/knowledge/DATA_MODELS.md`):** Diccionario de entidades, tipos de datos, claves primarias/foráneas y restricciones.
4. **Matriz de Trazabilidad (`docs/traceability/TRACEABILITY-MATRIX.md`):** Trazabilidad bidireccional desde el Requisito EARS hasta el test de verificación.
